# MM INSTALACE: ukázka webu

Statický web pro GitHub Pages. Soubory nahrajte do kořene repozitáře a v Settings, Pages zvolte větev `main` a složku `/ (root)`.

Ukázka je schválně skrytá před vyhledávači (`noindex` a `robots.txt`). Při ostrém spuštění tyto dvě věci odstraňte.

Formulář: klíč Web3Forms nebo Formspree se vkládá do `js/config.js`. Bez klíče se otevře e-mail.
